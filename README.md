# IMB (Intelligent Mind Butler)

**IMB** 是一个基于大模型的个人决策辅助系统。它不仅仅是一个聊天机器人，而是你的私人管家、研究员和成长伙伴。

## 核心愿景

> "收集信息，辅助决策，积累成长。"

当你面临复杂任务（如投资、择业、旅行规划、技术选型）时，IMB 会：
1.  **像管家一样**：通过对话理清你的真实需求。
2.  **像研究员一样**：利用网络工具自主收集资料、整理数据。
3.  **像秘书一样**：将碎片化信息整理成结构化的「决策文档」。
4.  **像伙伴一样**：帮你归档这些智慧，形成个人的知识库。
