## API端点说明

前端调用的API端点（需要后端实现）：

### 任务管理
- `POST /api/ai/tasks` - 创建任务
- `GET /api/ai/tasks` - 获取任务列表
- `GET /api/ai/tasks/{taskId}` - 获取任务详情
- `PATCH /api/ai/tasks/{taskId}/status` - 更新任务状态
- `DELETE /api/ai/tasks/{taskId}` - 删除任务

### 对话管理
- `POST /api/ai/tasks/{taskId}/conversations` - 创建对话会话
- `GET /api/ai/conversations/{conversationId}/messages` - 获取消息历史
- `WebSocket: /ws/ai/conversations/{sessionId}` - WebSocket对话

### 笔记管理
- `POST /api/ai/tasks/{taskId}/notes/generate` - 生成笔记
- `GET /api/ai/tasks/{taskId}/notes` - 获取笔记列表
- `PUT /api/ai/tasks/{taskId}/notes/{noteId}` - 更新笔记
- `POST /api/ai/tasks/{taskId}/notes/{noteId}/regenerate` - 重新生成笔记
- `DELETE /api/ai/tasks/{taskId}/notes/{noteId}` - 删除笔记

### 知识库
- `POST /api/ai/knowledge/search` - 搜索知识
